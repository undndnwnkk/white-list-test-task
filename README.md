# Task:
Контекст. У нас есть отдел, который обзванивает организации и назначает
встречи. Нужна основа для внутренней CRM.
Задача. RESTAPI для учёта звонков и назначения встреч. Интерфейс не нужен
— только API.
Эндпоинты (минимум)

Бизнес-правила
Это самая важная часть задания — не количество эндпоинтов.
1. Длительность встречи — 60 минут.
2. Встречи только в рабочие часы: пн–пт, 09:00–18:00 по времени Asia/Almaty.
Встреча должна умещаться целиком: начало в 17:30 — отказ.

не 500.
Время в API принимайте и отдавайте в UTC (ISO 8601), а правила рабочих часов
проверяйте по Asia/Almaty.
Технические требования
Хранение — любая БД на ваш выбор, включая SQLite. Схема — миграцией
или SQL-файлом в репозитории.
Минимум 5 автотестов. Два из них обязательны: на пересечение встреч и на
границу рабочего дня.
Запуск одной командой из README. docker compose up — желательно, но не
обязательно.
Приложите файл с примерами запросов: curl, .http или коллекция Postman.
Авторизация, роли, очереди, уведомления и кэш не нужны. Если добавите — это
не плюс.
